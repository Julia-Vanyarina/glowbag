# glowbag

Личное приложение для iPhone: косметичка, которую можно разбирать пальцем, каталог, схема ухода, любимое и анализ средств.
Данные хранятся только на телефоне. В GitHub лежит только код.

## Главная механика — косметичка
- Средства торчат из косметички. Тап — карточка средства.
- Тяни средство:
  - на **стол** — достать то, чем пользуешься сегодня (место запоминается);
  - на **«в уход»** — выбрать утро / день / вечер / раз в неделю;
  - на **«любимое»** — добавить или убрать из любимого;
  - на **«на полку»** — убрать из косметички (средство останется в каталоге);
  - обратно в **косметичку**.
- Тап по косметичке — она встряхивается.

## Что ещё есть (2.1)
- **Уход → календарь** — тепловая карта по дням, точки — вечера с Азеликом, серия дней подряд. Нажми на прошедший день, чтобы отметить забытое.
- **Уход → ❄ / ☀** — зимняя и летняя схемы, переключаются одной кнопкой.
- **Профиль → напоминания** — события для календаря iPhone (.ics): Азелик каждый вечер, конец паузы, сроки годности, бэкап раз в неделю, смена сезона.
- **Карточка средства → «Разобрать состав»** — вставь INCI, активы отметятся сами.
- **Корзина вверху → покупки**: список (заканчивается, купить снова, хочу, заказано), пустые баночки с отметкой «куплю снова / не куплю», траты по месяцам.

## Как выложить на GitHub Pages
1. Загрузи все файлы из архива в репозиторий (папки `css`, `js`, `icons` и файлы в корне).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
3. Открой `https://<логин>.github.io/<репозиторий>/` в Safari → «Поделиться» → «На экран Домой».

Если первая версия («Косметичка») уже стоит на телефоне — загрузи файлы **в тот же репозиторий**, поверх старых.
Тогда данные перейдут сами. Если делаешь новый репозиторий — сначала сохрани копию в старой версии и восстанови её в новой (Профиль → Восстановить).

## Как обновлять
1. Замени файлы в репозитории.
2. Поменяй номер версии в трёх местах: `APP_VERSION` в `js/data.js`, `VERSION` в `sw.js` и `version` в `version.json`, добавь запись в `CHANGELOG`.
3. В приложении: Профиль → «Проверить» → «Обновить». Данные не теряются.

## Бэкап
Профиль → «Сохранить копию» → «Поделиться» → «Файлы» или Яндекс Диск.
Восстановление: Профиль → «Восстановить». Подходят копии и glowbag, и старой «Косметички».
Если копии не было больше недели, на главной появится напоминание.

## Шрифты
Bricolage Grotesque, DM Sans и Fraunces — только латиница. Русский текст набирается похожими Rubik, Onest и Lora.
